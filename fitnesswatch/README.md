# Fitness Watchiki

**GVH Hackathon project.** How a fitness watch reads steps (MEMS accelerometer) and heart rate (optical PPG) — plus sleep as a firmware pattern, not a third sensor.

Full write-up, run instructions, and pitch notes: see the [root README](../README.md).

## Quick start

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).
